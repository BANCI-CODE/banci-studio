01 / EXHIBITION KEY VISUAL

白色，是画面的主角。

在深蓝的人物剪影与暖色空间之间，以白 T 恤建立视觉焦点。画框、门口与人物构成观看关系，红色底座收住画面，让展览主题与信息层级清楚落位。

图形

人物与白 T 恤形成反差，连接艺术形象与日常衣物。

空间

墙面、画框与门洞引导视线，建立展览场景。

信息

标题与底部信息分层组织，让远看识别与近看阅读各有位置。

02 / DIGITAL APPLICATIONS

同一个主题，
适应不同的阅读比例。

微信头图以横向构图连接标题与人物；竖版传播保留空间的纵深与完整角色。调整画面比例，让核心识别在不同入口保持连续。

WECHAT / 横版头图

适合文章入口的横向版式，突出项目名称与主视觉。

MOBILE / 竖版传播
03 / VISUAL APPLICATIONS

从一张海报，
延伸到展览的相遇。

作品集总览将主视觉与环境展示放在一起，纸张样机呈现图形在印刷媒介中的阅读效果。
