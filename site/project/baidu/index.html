01 / DUDU / VISUAL SYSTEM

亲切的形象，
来自清楚的规则。

从标准图形到比例、色彩和表情，建立可重复使用的角色语言。规范既保留小度熊的性格，也为不同媒介中的一致呈现提供依据。

色彩与背景适配

标准色、明暗背景与辅助色，让同一个角色适应不同传播环境。

动作与情绪，构成角色的日常。

03 / TEAM IDENTITY

不同团队，
各有自己的姿态。

华南九大运营标识将团队代号、字形与角色动作结合，在统一的插画语言中形成各自的辨识度。行业一部标识则以流动的形态与渐变色构建部门识别。

04 / INDUSTRY CONFERENCE

行胜于言，
奋勇争先。

2023 华南全员沟通会暨优秀表彰大会，以蓝紫色舞台视觉、向上的空间构成与醒目的主题字连接现场。主背景、舞台易拉宝与会场指引沿用同一套视觉语言。

CHARACTER / COMMUNITY / CONNECTION

从一个表情，
到一场相聚。

用角色建立亲近感，用系统保持一致性，
让品牌在日常与现场都被记住。
