THE PROJECT

让充电状态被看懂，
让日常使用有回应。

以 70W 双 USB-C 充电器为核心，围绕小屏幕与单一物理按键建立信息、操作和反馈关系，再将产品语言延伸到包装、产品资料与营销画面。这里将交互原稿、视觉探索和交付物分别呈现。

01 / INTERACTION ARCHITECTURE

先定义路径，再绘制界面。

开机与设备识别建立起点，功率、温度与累计能量承担状态读取；充电模式和轻量工具通过按键进入，屏保与熄屏形成返回路径。

ONE BUTTON / FOUR ACTIONS

一个按键，四种明确操作。

以下按原始交互说明整理，展示设计方案中的操作映射。

单击

切换当前显示界面。

双击

确认选择，进入或退出小程序。

三连击

直接切换充电模式。

长按

进入快速轮播，松开停留在所选界面。

02 / DISPLAY SYSTEM

完整状态，共享一种阅读方式。

从设备连接到总功率、分端口功率、温度与累计能量，用一致的画面层级表达变化。保留原稿的完整排列，点击可查看细节。

03 / FEEDBACK & CHARACTER

功能之外，给日常一点回应。

将充电模式、番茄时钟与轻量趣味反馈分别组织。连续画面展示动效的关键状态，便于同时检查状态变化与视觉一致性。

04 / PACKAGING & DELIVERY

体验延伸到开箱之后。

彩盒通过产品形象、型号与功能层级帮助识别；使用指南把硬件结构和操作说明带入交付。展示的是项目包材设计稿。

05 / BRAND TOUCHPOINTS

从产品语言，到品牌触点。

在袋装物料、宣传画面与产品资料中延续品牌识别。以不同画面尺度承接产品信息，而非把屏幕设计直接放大。

06 / VISUAL DEVELOPMENT

用场景解释产品的性格。

以产品渲染、使用场景与视觉探索连接功能和感受。不同方案保留各自的表达目的，帮助比较产品如何进入用户的日常环境。

REFLECTION

让功能、反馈和品牌
说同一种语言。

小屏设计的工作不仅是安排像素，也包括定义用户何时获得信息、怎样触发操作，以及产品离开屏幕后如何继续表达自己。
