THE CHALLENGE

Technology
needs translation.

新品牌没有历史信任，产品又拥有复杂的 AI 视觉、导航和机械系统。设计需要先减少理解成本，再建立专业感与购买信心。

01

看懂

让用户快速理解产品是什么、能解决什么问题。

02

相信

让视觉、产品与信息共同传递可靠的技术实力。

03

购买

让包装、渠道与营销在不同市场中保持同一套语言。

PRODUCT LANGUAGE

Start with
the machine.

品牌语言必须从产品结构中生长。TRON 的机械骨架、环形轮组和感知模块，成为视觉系统中“精密、运动、智能”的基础语义。

BRAND SYSTEM

One language.
Many touchpoints.

我将产品特征转译为可重复使用的品牌规则：克制的黑白基础、识别性绿色、精密线框与清晰的信息层级。

“不是增加更多科技感，而是让每一次接触都更容易理解。”
PACKAGING / 包装与开箱

One family.
Every detail.

主机、配件和安装资料需要作为一个整体被理解。以产品命名、线稿与信息分区建立系列识别，让包装从运输容器成为第一次使用的入口。

大包装建立识别

主机箱以 TRON 名称、机身线稿和品牌标识构成第一层信息。牛皮纸底色与黑色图形让大型箱体保持清晰、直接的产品表达。

小包装区分产品

配件沿用统一命名与图示位置，结合不同尺寸和底色区分品类。系列感来自共同的信息规则，也给每一款配件留下识别空间。

交付连接使用

从外箱识别、配件清点到快速安装指南，将用户需要的信息放到对应的开箱步骤中，接续硬件的第一次使用。

DESIGN DECISION

材料有差异，
信息有秩序。

主机箱以牛皮纸与黑色印刷建立稳定识别；配件包装按品类保留不同的尺寸与色彩。统一的核心，是名称、图示与说明之间的层级关系。

DESIGN RATIONALE / 原始设计思考

让材料、图形与信息一起工作。

最初的问题是牛皮纸箱的价值感不足。方案把天然纸色与版画式单色图形结合，突出产品、型号与品牌，再让功能和运输信息进入次级阅读层。设计同时回应产品保护、物流识别与市场展示的需要。

IN-BOX SYSTEM / 包装内部信息架构

开箱之后，信息才真正开始工作。

先清点，再安装，再连接设备，最后进入长期使用。说明书、小提示与售后卡分别承担不同的信息任务。

  1. 清点配件标签 / 爆炸图
  2. 准备开箱小提示 / 场地条件
  3. 安装充电站 / RTK / 快速指引
  4. 连接下载 App / 添加设备
  5. 使用用户手册 / 维护说明
  6. 服务维保卡 / 延保卡
QUICK START / 安装说明

从一张总览，到逐步操作。

保留快速指引完整展开画面，并单独展示安装、场地选择和设备连接页。大图可点击放大，阅读图例与正文。

SMALL DETAILS / 开箱小提示

把容易忽略的事情，放到眼前。

用图例区分部件，用正误对比解释草坪准备与使用条件；这些小页面与主说明书互相补充。

EXHIBITION / 展会与沟通

A brand
you walk into.

将品牌从平面延伸到空间：远处看见 AIRSEEKERS，走近理解 TRON，再通过产品、图解与资料展开交流。不同尺度的展台共享同一套视觉语言。

远处 / 品牌识别

把品牌名称和草坪场景放到大尺度立面上，在展厅环境中建立清楚的视觉入口。

走近 / 产品理解

通过机身大图、技术说明与实物陈列组织信息，使产品展示与功能解释相互补充。

停留 / 深入沟通

将产品体验、资料展示与交流区域联系起来，让展会中的观看能够继续转化为具体对话。

EXHIBITION KIT / 展会物料体系

从空间识别，到一份能带走的资料。

展台负责建立第一印象，展板与易拉宝解释产品，折页和 A4 资料承接深入阅读，桌牌、名片和互动道具连接现场沟通。

PRINT / 平面信息系统

A4 宣传册与产品折页

应用效果与展开原稿并置，既看整体气质，也能读到正反面的产品信息。

ROLL-UP / 竖向展陈

两个型号，同一套阅读秩序。

完整保留易拉宝的长幅比例：产品与型号先被看见，功能图解向下展开，品牌与入口在底部收束。

ON-SITE / 展台内部与互动

小物料，连接现场的每一次交流。

邀请函用于会前沟通；名片、桌牌与二维码卡承接现场交流；手提袋和手举牌延伸品牌在展厅中的可见度。

WEBSITE + APP / 数字体验

Understand it.
Then use it.

网站回答“这台机器能做什么”，App 回答“它正在做什么、完成了什么”。沿着了解产品到日常使用的路径，把品牌视觉转化为清晰的信息与反馈。

WEBSITE / PRODUCT STORY

先建立认知，
再展开技术。

用真实的草坪场景引入产品，再以图解、局部细节和功能说明展开能力，最后衔接 App 与品牌介绍。产品图负责建立印象，信息层级负责帮助理解。

TRON APP / PRODUCT EXPERIENCE

让机器人的复杂能力，
成为清楚的日常操作。

从首次连接到日常割草，把设备、地图与任务组织成连续的操作路径。以下展示原始设计稿的完整屏幕，横屏建图与竖屏管理分别保留原有比例；不同迭代的界面用于说明各自的设计问题。

  1. 连接设备蓝牙 / 家庭网络 / 绑定
  2. 建立地图边界 / 禁区 / 保存
  3. 安排任务区域 / 时间 / 参数
  4. 实时控制状态 / 遥控 / 进度
  5. 持续管理记录 / 家庭 / 固件

连接，让每一步都有反馈。

将网络选择、连接权限与绑定结果拆成明确步骤，让用户知道当前进度与下一步。

建图，把空间规则直接放到地图上。

横屏为地图与遥控操作留出足够空间。教程、边界绘制、禁区与保存设置共同构成建图过程。

任务，把计划与运行状态连在一起。

任务列表负责组织多次作业，时间设置表达日程，运行面板提供当前作业进度。

管理，覆盖使用之后的长期维护。

记录帮助回看作业，家庭成员和个人中心承接日常管理，固件反馈让更新过程可被理解。

统一组件，维持操作的一致性。

用统一的控件、图标和状态表达连接不同功能，减少重复学习。

网站，从了解产品到进入体验。

以完整长页呈现产品叙事、功能说明和使用场景。下方窗口可上下滚动，点击图片可放大查看原稿。

界面中的设备、地图与数值均为设计稿示例，用于呈现信息结构与交互状态。

APP / PRODUCT FEEDBACK

把运行数据，
变成可读的反馈。

任务列表组织日常作业；割草报告以面积作为主要结果，工作时长、充电次数与覆盖率作为补充信息。品牌色、产品形象与数据层级共同连接硬件和屏幕。

REFLECTION

Brand design for intelligent hardware is the work of translating technology into trust.

WHAT I LEARNED

设计负责人建立的不是一组视觉资产，而是一套让产品、工程、市场与供应链能够共同判断的语言。

WHAT CHANGED

工作重心从“完成品牌视觉”转向“定义决策标准”，让包装、展会与网站 App 在不同使用情境下保持清晰、一致。

WHAT I WOULD IMPROVE

下一阶段会更早建立可验证的包装原型与跨市场用户测试，让安装信息、多语言层级和开箱节奏在投产前得到更充分验证。
