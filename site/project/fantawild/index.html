KEY VISUAL / PARK & CAMPAIGN

让乐园的想象，
在一张画面里发生。

以建筑、游乐设施与角色建立主视觉，让不同乐园拥有鲜明的场景记忆，再延展到开园传播与节日活动。

把乐园写进字里。

以大字作为画面中心，将过山车、水景与主题建筑融入笔画和空间；统一构图节奏，通过配色与场景区分不同乐园。

绵阳开园 · 地域与乐园相遇。

借用火锅的热烈氛围组织场景，将东方建筑与神话角色汇入同一幅画面，让开园传播与城市生活建立联系。

节日活动的不同语气。

春节用团圆场景聚拢情绪，五一通过手写文字与游玩实景表达假日心情，同一品牌随活动切换视觉语气。

ILLUSTRATION / SEASONAL STORIES

把节日情绪，
画成值得停留的一幕。

围绕季节、民俗与角色关系组织画面，用完整场景传递祝福，也让乐园自然成为节日故事的一部分。

七夕 · 隔着山水，也能相遇。

以桥梁串联乐园建筑，利用前景水面与远景山色拉开层次；横竖版沿用同一场景，使画面适应不同传播位置。

万圣夜 · 角色带动气氛。

以紫蓝夜色、南瓜与夸张的角色动作组织节日识别，让不同年份的活动保有各自的画面主题。

诗词与场景，共同构成画面。

将诗词文字、人物与东方建筑组合，通过留白与层次安排阅读顺序，让文化主题融入乐园的游览场景。

COMMERCE / VISUAL SYSTEM

从一张海报，
到清楚可辨的商品入口。

将乐园体验图与票种信息分层：主体画面呈现游玩场景，底部信息条集中承载目的地、票种和店铺标识。

统一结构，容纳不同产品。

一日票、联票、季卡与年卡沿用相同的信息位置，通过色彩与标签区分产品，保持主图在商品列表中的一致性。
