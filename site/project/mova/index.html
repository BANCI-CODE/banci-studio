01 / CONTEXT

A charger became
an interface.

产品是一款紧凑型智能充电器。屏幕需要在极短时间内解释功率、温度、端口、计时与异常状态，而用户只有一个物理按键可以操作。

设计任务不是为小屏增加更多功能，而是定义什么信息必须出现、何时出现，以及用户如何在不阅读说明书的情况下完成操作。

03 / INFORMATION ARCHITECTURE

Priority before
interface.

信息结构按“即时状态 → 操作反馈 → 系统设置”分层。功率、端口与异常优先出现；计时和工具功能在用户主动操作后进入；低频设置不占据默认界面。

01

NOW

当前功率、端口、温度和充电状态，回答“设备此刻是否正常”。

02

ACTION

按键后立即反馈已触发的模式，降低误操作和重复点击。

03

UTILITY

计时、复位、熄屏等低频功能保持可达，但不干扰日常读取。

04 / SINGLE BUTTON LOGIC

One control.
Five intentions.

不同手势按使用频率和风险排序：高频操作最短，具有破坏性的操作最难误触，并始终提供即时状态反馈。

  1. 01SINGLE CLICK

    切换主要状态；高频、低风险，保持最低记忆成本。

  2. 02DOUBLE CLICK

    进入次级工具，避免与日常查看冲突。

  3. 03TRIPLE CLICK

    触发低频功能，以更明确的节奏减少误操作。

  4. 04LONG PRESS

    用于需要确认的模式切换，持续按压即成为意图确认。

  5. 05RESET

    与普通操作分离，并通过完整反馈说明系统已恢复。

05 / UI SYSTEM

22 states.
One mental model.

22 个状态不作为屏幕墙平铺，而是被组织为五组行为：用户先识别状态，再理解变化，最后决定是否操作。

01

STATUS

待机、连接、温度与设备状态。

02

CHARGING

功率、端口、进度与充电反馈。

03

SYSTEM

模式、熄屏、设置与复位。

04

UTILITY

计时器与辅助功能。

05

EMOTION / INTERACTION

像素化的情绪反馈与轻量陪伴。

06 / MOTION AS FEEDBACK

Motion explains
state change.

动效只承担状态反馈：确认输入、连接变化、充电节奏和异常提示。它不装饰屏幕，而是帮助用户判断系统是否已理解自己的操作。

07 / PRODUCT CHARACTER

Useful can still
feel human.

复古功率表、快慢模式、番茄计时、Good Luck 与像素视觉都使用低分辨率、短反馈和明确隐喻，适合小屏显示，也不会干扰核心充电信息。
