01 / IDENTITY

识别，从一笔开始。

书写感的中文字标，与橙色笔触、英文名称共同组成品牌识别。两版 VIS 的探索，从清新的自然意象走向更鲜明的字形、色彩与应用语言。

VIS 1.0 自然与秩序

标志组合、色彩与字体，让自然意象成为可延展的识别基础。

VIS 2.0 笔触与表达

保留书写的力度，以更丰富的色彩与图形建立品牌声音。

02 / KEY VISUAL

把山野，带到眼前。

以自然风景、产品光感与大字号信息构成传播画面。“五感”系列探索字、形、意、构、色的变化，公众号视觉则延展到产品、品牌故事与活动邀请。

五感 字 · 形 · 意 · 构 · 色

03 / PACKAGING & PRINT

从看见，到拿在手里。

瓶贴、盒型、手提袋与开箱卡片组成连续的开箱体验。成品效果与印刷展开并置，呈现图形如何适应透明瓶身、纸张和运输包装。

印刷与交付 细节保持一致

04 / STQ MINI PROGRAM

把品牌故事，
接到商品体验里。

从商品主图到详情阅读，以一致的绿色视觉串联产品介绍、产地、酿造与使用场景。长图保留完整阅读顺序，在手机视窗中向下滚动查看。
