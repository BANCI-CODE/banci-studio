# AKU 图片用途规范
正方形：365天进度点阵预览；缺少确认素材时用原图contain完整显示，禁止错误编号替换。
长方形排版：Daily抽卡，完整呈现；原始尺寸无损WebP。
长方形带字：抽中已有文字版本的作品时显示「查看文字版」，独立打开高清图；未制作作品不显示入口。
十二个月YEAR CALENDAR保留原素材。原文件不删除。匹配按作品名称优先并结合编号，不能仅按目录排序。
本轮190正方形、200长方形、37文字版匹配；未确定条目见aku-format-unresolved.json。图片原始像素不变，lossless WebP，无降分辨率或有损重编码。
Journal沿用系统gutter与4px间距阶梯，编号随figcaption留16px内边距，手机/平板/桌面1/2/3列。

Daily配文为本次原创的文学性短文，以现有作品标题为灵感，不作为作者原述或画面事实说明。203个可抽取条目均有独立配文；未展示的整理中条目不虚构作品。
