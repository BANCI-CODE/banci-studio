THE PROJECT

让充电状态被看懂，
让日常使用有回应。

围绕 70W 双 USB-C 智能充电头，重点展示小屏 UI 与单键交互设计：从信息架构、操作路径到状态反馈，再延伸到充电头的外型、配色与使用场景。

01 / INTERACTION ARCHITECTURE

先定义路径，再绘制界面。

开机与设备识别建立起点，功率、温度与累计能量承担状态读取；充电模式和轻量工具通过按键进入，屏保与熄屏形成返回路径。

ONE BUTTON / FOUR ACTIONS

一个按键，四种明确操作。

以下按原始交互说明整理，展示设计方案中的操作映射。

单击

切换当前显示界面。

双击

确认选择，进入或退出小程序。

三连击

直接切换充电模式。

长按

进入快速轮播，松开停留在所选界面。

02 / DISPLAY SYSTEM

完整状态，共享一种阅读方式。

从设备连接到总功率、分端口功率、温度与累计能量，用一致的画面层级表达变化。保留原稿的完整排列，点击可查看细节。

03 / FEEDBACK & CHARACTER

功能之外，给日常一点回应。

将充电模式、番茄时钟与轻量趣味反馈分别组织。连续画面展示动效的关键状态，便于同时检查状态变化与视觉一致性。

04 / PRODUCT FORM

把屏幕、按键与接口，
组织成一个完整的产品。

外型设计围绕带屏充电头展开：顶部屏幕成为信息焦点，机身承接触控位置与双 USB-C 接口。通过不同视角和配色方案，展示屏幕轮廓、机身体量及表面表现之间的关系。

REFLECTION

从看懂屏幕，
到理解如何操作。

UI 提供清楚的信息，交互连接操作与反馈，外型则承接屏幕、按键和接口。三者共同定义这枚智能充电头的使用体验。
