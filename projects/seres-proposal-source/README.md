# BEYOND THE MACHINE.

赛力斯消费级机器狗新品上市视觉方向网页提案。Vite + React + TypeScript + 原生 CSS，在当前目录直接开发；不依赖外部图片、字体 CDN 或后端服务。

## 启动与构建

环境：Node.js 20.19+ 或 22+，npm。

```sh
npm install
npm run dev
npm run build
npm run preview
```

`build` 先执行 TypeScript 严格检查，再生成 `dist/`。开发地址以终端输出为准。部署时将 `dist/` 交给静态服务器；不要直接双击 HTML。若部署到子目录，请运行 `npm run build -- --base=/your-path/`，并确保该路径部署完整的 dist 内容。

## 内容结构

1. Cover：主题、中文主张与留白空间。
2. Project Understanding：目标人群假设、定位建议、传播路径。
3. Three Creative Pillars：时尚、先锋、品质三大视觉方向与执行规则。
4. Visual Language：色彩、字体、12列栅格、摄影、光影和动效。
5. Campaign Application：官网、海报、社媒、产品细节版式示意。
6. Creative Conclusion：统一主张与下一步执行路径。

## 文件

- `src/main.tsx`：章节内容、图片清单、导航、图片失败兜底与滚动观察器。
- `src/styles.css`：设计令牌、12列栅格、700/1000/1550px适配、减少动态效果和打印样式。
- `public/references/`：全部本地图片资产，含19张用户提供的研究参考与5张抽象SVG。
- `IMAGE_GUIDE.md`：图片清单、替换方式、拍摄及授权要求。

## 设计与交互

纸白 `#F7F7F5`、展厅灰 `#EEEEEC`、混凝土灰 `#D4D4D0`、石墨灰 `#646460`、墨黑 `#171715`。英文主标题采用本地 Impact / Arial Narrow 回退字体，中文采用系统黑体；无网络字体请求。核心视觉是偏移的大标题、真实产品预留的空白空间以及错位的三组视觉研究。字体不是官方品牌规范，发布前应核对授权和品牌字体。

桌面固定章节导航；手机可展开目录，支持 Escape 关闭。原生锚点支持分享章节、键盘操作与浏览器前进后退。IntersectionObserver 提供当前章节提示和单次滚动渐显，系统减少动态效果时关闭动画。图片加载失败时显示带文字的稳定占位，无破图图标。

## 打印 / 导出 PDF

点击顶部“打印提案”，在浏览器中选择“另存为 PDF”。建议 A4 纵向、100%缩放、开启背景图形、关闭浏览器页眉页脚。打印样式隐藏导航和交互控件，展开全部动画内容，以章节分隔，并尽量避免图文块断页。不同浏览器的字体回退及分页可能略有差异；正式交付 PDF 前请检查打印预览。

## 内容边界

本项目是创意提案，并非赛力斯官方发布页面。没有提供品牌手册、样机照片、结构、材质、功能或参数资料，故未虚构产品形象、研究数据或能力。文中的人群、定位及场景为待验证的创意建议；所有抽象 SVG 都明确作为视觉意向，不代表产品。后续已接入用户收集的19张第三方参考图，并显式标注为非赛力斯产品；仅用于内部视觉方向讨论，作者及使用授权待确认。SERES 为文字标识，未仿绘官方图形商标。未复刻第三方品牌页面；视觉系统研究区展示用户提供的参考作品原图，用于比较与讨论，不作为本提案的原创品牌资产。
