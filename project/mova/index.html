01 / BACKGROUND

From charging tool
to intelligent companion.

传统充电设备主要解决能源传输，但当屏幕和智能能力进入小型硬件，它也可能成为人与数字服务之间的新入口。

我参与产品早期定义，探索硬件、界面与智能交互如何协同，而不仅是完成一组 UI 画面。

02 / CHALLENGE

How can a small screen create meaningful interaction?

01

Limited space

小尺寸屏幕要求信息有明确优先级。

02

Limited attention

用户只需要在关键时刻看懂设备状态。

03

Limited learning

交互必须自然，不能要求用户学习复杂菜单。

03 / PRD THINKING

From design request
to product definition.

  1. 01User Scenario
  2. 02User Need
  3. 03Function Definition
  4. 04Interaction Logic
  5. 05Interface Design

例如用户夜间回家时，真正的需求不是浏览功能，而是快速确认充电状态、时间与异常信息。

04 / INTERACTION FRAMEWORK

Action → Intelligence
→ Feedback.

交互逻辑围绕“降低认知负担”建立。用户输入触发设备识别，系统根据状态判断，再用最少的信息给出可理解的反馈。

INPUT01User action
SYSTEM02Device intelligence
OUTPUT03Visual feedback
05 / AI PRINCIPLES

AI changes the
interaction relationship.

Context before command

设备先理解时间、连接状态与能量需求，再决定何时提供建议。

Plain language before codes

异常信息从错误代码转化为清晰原因与下一步操作。

Useful initiative before interruption

主动反馈只发生在真正能减少操作或风险的关键时刻。

06 / PATENT EXPLORATION

Turning interaction logic
into an original concept.

在探索过程中，我提出了一套新的交互逻辑方案，并基于方案推进专利申请。价值不在于“拥有专利”，而在于能将洞察转化为可描述、可验证、可保护的新体验结构。

07 / REFLECTION

Future hardware will become an intelligent interface connecting humans and AI.

项目受成本和研发资源限制，并未完全实现 AI 能力。它仍然改变了我对产品设计的理解：设计师需要定义关系、信息与行为，而不只是界面样式。
